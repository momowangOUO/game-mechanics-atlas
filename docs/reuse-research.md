# 可复用资源检查

2026-10-30 已检查本地资源、GitHub 项目、官方文档与 npm 元数据。当前决定为组合成熟小型依赖，并自建产品数据与分析规则，不套用 Dashboard 模板。

|资源|采用内容|授权/成本|依据与限制|
|---|---|---|---|
|[Next.js](https://github.com/vercel/next.js)|页面路由、静态内容和本地开发|MIT；无需托管账号|官方安装说明与 npm 元数据；尚未安装执行|
|[React Flow / XYFlow](https://github.com/xyflow/xyflow)|拖动、缩放、节点与连线|MIT；基础能力无需Pro|已读官方仓库和LICENSE；需要在产品中验证节点筛选与高亮|
|[Motion](https://github.com/motiondivision/motion)|转场、布局与轻量角色反应|MIT；基础动画无需付费|已读官方LICENSE与[可访问性文档](https://motion.dev/docs/react-accessibility)，支持减弱动态|
|[Zod](https://github.com/colinhacks/zod)|数据校验|MIT|已读官方仓库和LICENSE；跨实体语义仍需自建检查|
|已安装 auto-design-scout|真实参考选择、元素混合、项目状态持久化|本机Node；无新增账号|doctor检查通过，服务已运行；不以默认通用参考代替当前研究|

没有采用整站SaaS后台模板：用户明确要求2000年代日系动画/视觉小说气质，现成后台结构不能满足角色、美术与交互主题。机制模型、需求/供给分析和规则实验室需要按本次领域不变量编写。

公开资料可作研究并不等于允许复制素材。官方游戏角色和官网图片只在参考板按来源展示；正式站点采用原创角色与自制图形。研究覆盖不是穷尽所有开源产品，实际运行测试会另行记录。
