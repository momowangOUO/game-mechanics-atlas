# 收录范围

本站整理电子游戏的机制与设计案例，不收录纯赌博、博彩投注和传统棋牌类作品。彩票、赛马投注、赌场、麻将、象棋、围棋等词条不进入近期游戏趋势。

收录不限平台与年代，优先考虑有代表性且有商业或受众证据的作品，包括已正式开放的抢先体验版本。不收录尚未实际发行的 Game Jam 作品和过度小众的候选。

可用证据包括公开销量、玩家里程碑、明确的商业销量榜，以及持续的直播或传播成绩。没有公开总销量不等于表现不足；评论数、下载量、观看时长和同时在线人数保留各自口径，不换算成销量或累计玩家人数。作品获奖或媒体评分可以辅助发现，但不能单独证明受众规模。

机制资料尚未补齐时，可发布注明资料缺口的“参考条目”，只记录已核实机制。缺少商业或受众证据的候选暂缓发布，研究材料保存在归档中；暂缓不表示已证明玩家人数低于门槛。用户明确指定的《万手一体》继续保留，未获得的商业规模数据仍标为未知。

每类十款案例仍是补查目标。收录质量和分类准确性优先，不靠牵强贴标签或冷门作品填满数字。首次发行年代采用原作首次公开发行年，分为 2010 年及以前、2011–2019 年、2020 年及以后；移植不另算一款游戏。

卡牌、骰子、牌型、转轴等可以成为现代电子游戏的规则素材。Balatro、幸运房东、领土与 Game of Dice 按各自的构筑、计分、资源或对抗规则分析，不能因为使用这些素材，就与纯赌博或传统棋牌合并。

近期搜索快照只发布已核对游戏名称的词条和对应来源片段。Google Games 分类中的其余词条不进入本站数据；完整网页仅作为本地核对记录保存在忽略目录中。
