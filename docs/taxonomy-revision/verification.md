## 主要结果

- 首页、章节、导航与全局搜索以分类参考为主要入口。
- 9 个规范维度 → 50 个编辑分组 → 122 个机制 → 有范围的游戏实例，完整覆盖且不重复。每个分组说明用途、作用与边界，典型参照直接引用现有观察。
- 32 个复合类型增加玩家任务、三步玩法过程、设计问题、相近类型差别，以及具体可观察的规则与范围。
- 游戏详情读取并验证 `scope` 链接，不再错误回到默认模式；冲突的分类参数以机制的规范归属为准。
- 手机分类采用分步与分页；类型参照采用单列自然高度，证据紧接游戏卡。
- 默认合成热门榜已撤下，原数据移入隔离测试目录，正式导入拒绝合成记录。实际发布的 JavaScript 未发现原种子标识或虚构恐怖搜索记录。

## 真实数据与缺口

已实际取得并展示 Google 官方 2025 全球 Games 搜索飙升榜 10 条，保留原始词、名次、来源、采集时间、原文片段和 SHA-256。统计区间为 2025-01-01 至 11-25，对比上一年同期；这是历史增长名次，不是搜索总量，也不代表当前类别需求。

当前类别相对指数请求实际返回 HTTP 429；内置浏览器回退也因 Work 设置禁用而未取得数据。类别、机制、组合需求保持未取得，不能据年度游戏名次生成这些排名。当前暂停蓝海、红海分与机会排名，实际次数导入也不把本站有限样本当作完整市场供给。详见 [真实搜索资料](../real-search-demand.md)。

知识库保留 80 款游戏、122 个机制、32 个类型、32 组配方、120 条编辑关系；当前 704 条实例中，703 条为存在或条件成立，来源目录 148 项。121 个机制有可引用的存在或条件实例；后续对象预览保留证据缺口，没有套用其他 Tetris 作品规则。新增《极乐迪斯科》能力检定依据两项实际读取的官方资料。完整性校验不代替全部游戏实测或逐条独立事实审计。
