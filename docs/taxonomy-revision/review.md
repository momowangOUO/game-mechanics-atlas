# 内容与代码复核范围

本轮使用 clear-natural-writing 检查新分类说明、32 个类型阅读指引与界面提示。定义和分组是编辑归纳，游戏用法引用现有实例，保留来源、范围、状态与条件。

独立内容复核发现并修正三处问题：类型目录把类型写成了“类型配方”；生存割草说明预设所有作品都有自动攻击；类型参照只读默认范围，漏掉了已有的合作模式事实。现在类型与配方分开，自动攻击保留条件，类型参照选择一个有相关记录的实际范围，不拼接兄弟范围。

另一次只读代码复核检查分类覆盖、实例来源、类型范围、搜索指标与游戏范围参数，运行 21 项相关测试通过。复核指出冲突的分组与机制链接可能显示错位路径，已改为由有效机制确定规范分组，并增加回归测试。

实际生产截图还发现手机类型参照继承了首页的横向卡片样式，造成过窄卡片和空白。已使用局部样式明确网格布局、自然高度和手机单列，并增加卡片宽度、高度及证据间距检查。此问题由实际画面发现，不能由此前的行为测试通过推导为没有排版问题。

本次复核没有重新实测 80 款游戏，也没有对全部 704 条实例逐条作独立事实审计。新增能力检定实例另有两项实际读取的官方来源；后续对象预览保留证据缺口。最终构建、浏览器回归与当前截图以 [验收记录](verification.md) 为准。
