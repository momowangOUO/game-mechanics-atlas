# 品牌、署名与开场

本站由魔魔王架设，品牌资源仅包含已授权的动态与静态 Logo。`public/brand/` 保存公开使用的副本，不保存私人文件路径或其他来源材料。

## 页面展示

- 首页作者区、全站页脚、版权页显示 Logo、作者与版权信息。
- 桌面页头、手机导航菜单、首页作者区和页脚提供 GitHub 点星支持入口。
- 首页栏目使用“游戏范例”“机制模块关系图”“研究提示词”“搜索趋势”。
- `/copyright/` 与仓库 `COPYRIGHT.md` 分别说明原创资产和第三方游戏资料的归属，不增设代码许可证。
- AI / Agent 资料入口为 `/for-agents/`。

## 开场行为

`BrandIntro` 只挂载于根布局一次。每次整页打开与刷新都会播放，站内客户端跳转和同一文档的前进、后退不重新播放；不使用 sessionStorage 或其他访问次数标记。

开场先显示文字署名。Logo 及时加载后重新计时，确保 Logo 至少显示 3000 毫秒，再用 320 毫秒淡出；不等待其他页面资源。隐藏标签页的时间不计入显示时长。系统偏好减少动态时使用静态 Logo，满 3000 毫秒后直接退出。手写动画加载失败时改用静态 Logo；两张图片都失败或在署名显示期间未能加载时，保留文字署名并按时退出。

页面正文始终由服务端输出，开场是客户端挂载的独立覆盖层。禁用 JavaScript 时不产生覆盖层，仍能阅读正文和普通链接。

## 分享预览图

`public/brand/social-preview.png` 为 1280 × 640 PNG，组合品牌 Logo、站点名称与既有原创角色。`scripts/create-brand-preview.mjs` 使用项目已有的 sharp 渲染原生 SVG 排版并生成文件，不新增图像依赖。

该文件可用于页面 Open Graph 与 GitHub 仓库 Social preview。仓库 Social preview 需要单独在 GitHub 设置中应用；生成图片、添加网页元数据和修改仓库设置是不同操作，记录实际执行结果时应分别说明。
