# 跨平台案例扩充与漫画画风修正

日期：2026-11-02。

本文记录第一轮 459 款案例扩充及漫画修正。后续标签与收录审查已更新目录数量、补入热门作品，并暂缓发布证据不足的候选；当前情况见[热门补档与分类审查](../catalog-review/README.md)。下表与测试数量保留为该阶段记录。

## 内容范围

本轮从 82 款扩充至 459 款，包含 PC、主机、街机、掌机和手机作品。手机移植版沿用同一游戏条目，不重复计数。纯赌博与传统棋牌仍按[收录范围](../content-scope.md)排除；现代电子游戏使用卡牌、骰子或牌型，不据此直接排除。

新增游戏至少有六条带来源的机制记录。官方介绍、开发者资料、规则手册和第三方攻略分别保留来源类型；本站对玩法与分类的归纳标为编辑判断。没有把未检查的机制补成不存在，也没有声称完整穷尽每款游戏的规则。

传统类型与核心玩法分别注册。动作、冒险、射击等上位类型与子类型保留明确关系；平台、参与人数和题材不作为核心玩法方向。一款游戏可以包含多个主要玩法。组合查询必须在相同范围或明确父子范围内成立，不把互不相干的模式拼在一起。

## 覆盖与空缺

46 个传统类型和全部 21 个核心玩法方向至少收录十款游戏。语言解谜目前只有四款资料完整的案例；Sethian、Epigraph 等候选的机制依据不足，本轮没有为了达到数量目标强行收录。

47 × 21 共 987 个组合中，358 个已有案例，25 个留有检索后暂未找到案例的记录，604 个仍待补查。检索记录保存查询、范围、日期和实际参考链接，不代表已查遍所有市场。筛选后的空结果与待补查项不会触发 RIN 的蓝海台词；已检索的空缺也不附加市场机会评分。

新增入口：[/games/coverage/](https://momowangouo.github.io/game-mechanics-atlas/games/coverage/) 与 [/play-styles/](https://momowangouo.github.io/game-mechanics-atlas/play-styles/)。游戏目录可按传统类型、核心玩法、平台和原作年代组合筛选。目录与类型页面完整展开案例，不增加小分页。

数据保存在 [分批研究资料](../research/expansion/)，由 `scripts/import-expanded-cases.mjs` 汇总。`npm run check:coverage` 校验规模、分类范围、来源、图片和研究记录，语言解谜的缺口明确列为例外。机器阅读导出同步提供玩法方向、组合状态、作用范围和原始来源；没有新增虚构热度数据。

## 漫画与图标

新增对话选择、匹配消除、关键词检索、角色经验、消除充能五条机制，配套独立图标、三格漫画和规则示意图；另增对话选项分组插画。

首版对话与消除漫画偏向普通少年动画，人物比例、亮光与原素材不一致，已弃用。采用原有“跳跃”“直接移动”漫画及 Q 版 RIN 作为实际图像参考重画：保留粗轮廓线、Q 版人物、分块阴影、石木场景和暖色手绘背景。匹配消除另外修正了中间格子的匹配状态。

新漫画沿用旅人执行操作、RIN 陪同观察的分工；不会把被操作角色称为女仆。文案与数值仍由网页文字和 SVG 呈现。旧的 122 组图像没有被替换。[素材与校验值](art-assets.json)

游戏案例继续使用已有游戏代表图，保留来源与权利归属。官方素材和第三方资料图分别标注，未替游戏生成插画。实际抓取记录保留在本地忽略目录中，仓库只包含处理后的图片与来源信息。

类型检查、115 项单元测试、资料校验、组合覆盖校验和静态生产构建通过。完整浏览器回归发现的旧数量断言与懒加载检查已修正，相关 17 项回归全部通过。截图与发布检查见[验收记录](verification.md)。运行方式沿用根目录 README。
