# 分类图鉴、分组插画与连续阅读

2026-11-02

## 阅读方式

分类页保留九个维度。选定一个维度后，页面按顺序列出它的全部分组和机制，不再通过小分页逐条切换。桌面左侧目录可定位分组；手机把目录放在正文前。原有 `dimension`、`group`、`mechanic` 查询链接仍可使用，机制链接优先采用机制自己的固定维度。

每项机制依次展示大图标、定义、三格漫画、规则示意、游戏范例和设计说明。图解直接在页内展开，三格漫画在桌面与手机均竖排。每格原图为 600 × 600 像素，最大按原尺寸显示；小屏等比缩小。文字继续采用 HTML，规则示意采用 SVG，不把正文烘焙进图片。

机制图标放在正方形框中：桌面外框 160 像素、图像 128 像素；手机外框 128 像素、图像 112 像素。分组主图标在桌面显示为 96 像素、手机为 80 像素，目录使用小尺寸。图标只帮助识别，原有维度、分组、机制 ID 和五种状态没有改变。

九个静态维度介绍页和五十个分组页复用同一套机制内容。禁用 JavaScript 时，定义、图解、范例、来源与详情链接仍在 HTML 中。图片延迟加载，不要求一次下载整页漫画。

## 其他页面

- 游戏、机制、类型、来源目录展示全部筛选结果；全站快捷搜索也显示全部匹配。
- 游戏页按机制记录、核心循环、机制关系、搜索资料连续排列，共用当前研究范围。非默认模式没有整理循环时仍明确显示资料缺口。
- 对比页连续展示机制、结构与搜索资料，不省略表格后半部分。
- 研究提示词保留四个编写步骤，每步的候选、已选机制和参考配方不再分页；步骤操作栏固定在阅读区上方。
- 搜索趋势与热度计算沿用已有真实资料和导入逻辑，没有新增模拟热门榜。

## 素材与验证

50 张分组插画使用图像模型分别制作，采用项目既有的粗黑描边与赛璐璐配色。提示词、处理方式和完整性检查见[分组插画记录](../art/taxonomy-groups/README.md)。已有 122 组机制图标与漫画继续使用。

浏览器检查覆盖 320、390、768、1440 像素宽度，检查连续内容、图片比例、横向溢出、分类旧链接、模式范围、提示词编辑、复制与覆盖确认。新增检查还验证无 JavaScript 的静态分类页与超过 18 项的搜索结果。
