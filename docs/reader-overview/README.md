# 分类图解、RIN 台词与游戏机制总览

## 分类阅读卡

分类图鉴原先只在阅读卡中显示文字，漫画需要跳转机制详情页才能看到。本轮增加默认打开的“图解”页签，复用现有 122 组正式漫画与规则示意。窄面板逐格阅读，切换机制后回到第一格；定义、设计作用、游戏范例和分类区别仍有各自入口。

桌面与手机共用同一组素材，保持正方形分镜的比例。短屏调整图文排列，并提供“放大漫画”弹窗；放大时保留当前格，关闭后返回原位置。不截断说明或强制拉伸人物。

## RIN 的表达

台词集中在 `src/data/rin-dialogue.ts`。沿用黑发女仆研究助手的身份，本轮按用户要求加强活泼、好奇、略带得意的二次元语气，以“主人”称呼访客，配合欢迎、讲解、思考和发现机制卡的既有姿势。

角色说自己的想法、反应和邀请。分类、指标和按钮说明由普通 UI 承担，不让 RIN 朗读数据说明，也不把角色台词写成模型正在研究或已经替用户保存了资料。

## 多种交互与完整图谱

“核心交互”是机制分类维度，同一游戏可以同时包含多个交互机制。本轮在游戏页、游戏机制总览及提示词选择处分别说明这一点，未为游戏指定唯一的核心操作。

- 游戏详情的关系视图列出所选范围的全部已收录正向机制，取消“聚焦机制加最多六项相邻机制”的截取。没有关系记录的节点也保留。
- `/graph/?game=游戏ID` 默认汇总该游戏的全部已收录范围，按九个维度列出机制；可选择具体模式、章节或系统。
- `scope` 参数保留精确范围。其他游戏的范围 ID 不会混入，非法范围回到该游戏默认范围。
- 总览保留原始状态、条件及范围记录，不把不同模式拼成一套玩法。连线只允许出现在同一有效范围中共同存在的机制之间。
- 聚焦只改变高亮，保留其他节点。游戏图谱侧栏展示当前游戏中的用法与条件。

未知、不存在与不适用不会成为“已包含”的节点。总览显示的是资料库已经收录的内容，不声称已穷尽游戏的全部规则。
