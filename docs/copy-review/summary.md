# 网站文案审校与 MP4 录屏

本轮按 `clear-natural-writing` 技能重新审核并改写网站文字，覆盖界面标题、操作提示、空状态、报错、RIN 台词、知识条目与分析说明。当前生产构建为 `2WkLkVfiEGwEgGwg9UcPJ`，美术方向和正式素材沿用已确认版本。

## 审校范围

已阅读全部 15 个界面组件、17 个页面与路由文件，以及分类、热度、组合分析和素材说明中的读者文本。知识资料覆盖 52 条原子机制、18 款游戏、16 个复合类型和 10 组配方；三份研究 JSON 共修改 139 个文字字段。

机制 ID、规范名称、九维身份、实例状态、作用范围、来源链接、日期、数字、引用关系和计算公式保持原有语义。事实、设计判断与未核验事项仍分别说明。本次没有新增游戏事实或重新进行外部资料研究。

| 场景 | 本轮处理 |
| --- | --- |
| 初次进入研究室 | RIN 介绍身份并邀请选择游戏，不再假定用户是熟客。轮换建议也不依赖阅读历史。 |
| 搜索没有结果 | 显示“没有找到匹配的档案”，不据此断言数据库没有相关资料。 |
| 组合分析的相似参照 | 非 `present` 项显示“未匹配”；不把不存在、不适用或条件成立一律写成未知。 |
| 数据导入 | 区分格式与一致性校验、数据真实性；说明只在当前浏览器内存中生效，刷新恢复种子数据。 |
| 搜索与供给 | 保留搜索次数与独立人数、站内样本与市场总量、未记录与记录为零的区别。 |
| 游戏与机制说明 | 展开难懂的抽象表达，保留纳入条件、排除边界和证据限定。 |

独立文字终审提出的两处证据强度问题均已修正并复读确认，未发现尚未关闭的阻断项。分项记录见[界面](interface.md)、[知识条目](knowledge.md)、[方法与分析](methods.md)及[独立终审](final-review.md)。

## 显示与交互修正

导入错误的字段路径和合法枚举值保留，校验器的英文通用错误改成中文；非法 JSON 提示检查引号、逗号、括号和转义字符。失败仍整批拒绝，原有数据保持不变。

实际核对 Next 错误边界后，将错误页的回调属性修正为 `reset`，并增加先失败、修正后通过的契约测试。针对新版长说明，修正 768 像素下首页来源文字的横向溢出；热度便签按语义分行，避免把“竞品”拆开。

播放器优先加载 MP4，WebM 作为后备。已核对两个文件的摘要，并在 Edge 原生视频播放器中从开始播放至结束，检查 20%、50%、80% 处的实际画面。帧数与播放状态见编码记录；这属于视频播放验证，不是网页在真实手机上的性能测试。

可重跑以下命令。录制前先启动生产服务；转换使用 PATH 中的 FFmpeg／FFprobe，也支持 `FFMPEG_PATH`、`FFPROBE_PATH` 指定程序。

```sh
node scripts/record-galgame-motion.mjs
node scripts/verify-recording.mjs
```

仅重新转换已有录制源时运行 `node scripts/convert-recording.mjs`。录制与转换脚本会更新对应文件摘要和构建信息，转换后需重新执行播放验证。
