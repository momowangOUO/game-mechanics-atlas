## 台词与反馈的触发

- 首页初始显示第一条建议，点击对话框后依次切换其余三条，并循环返回。四句均可独立成立，不假定用户回访、已读案例或此前作过选择。姿势切换方式保留。
- 默认助手说明出现在实际调用 Assistant 的位置，只提供查阅建议，不假称已经完成研究。
- 实验室点击“分析当前组合”后显示分析快照；修改选项后继续保留旧结果及更新提示。完成章只表示规则分析完成，没有改成设计有效或市场成功。
- 热度页导入完成反馈发生在格式与一致性校验通过并替换记录之后。文案明确来源真实性仍需另行核验；文件只在浏览器内存中分析，刷新恢复合成示例。
- 搜索空状态来自当前关键词无匹配结果，不能据此认定知识库不存在相应档案。

## 重点修改

| 原文 | 修改后 | 原因 |
| --- | --- | --- |
| 欢迎回来。档案已经整理好了…… | 欢迎来到研究室，我是 RIN。想从哪款游戏开始？我们可以一起看看它的规则。 | 没有记录回访或已读历史，欢迎句应适用于首次和重复打开。 |
| 还没有这份档案 | 没有找到匹配的档案 | 搜索结果只证明没有匹配。 |
| 关系是独立的编辑实体 | 关系另行记录，机制所属维度保持不变 | 解释使用效果，减少实现术语。 |
| 点选查看档案 | 点选查看详情 | 点选打开当前详情面板，完整档案另有链接。 |
| 待确认／查看待确认项 | 未匹配／查看未匹配项 | 相似参照只把已确认存在记为匹配；其他状态还可能包括条件、不适用和已确认不存在，不能统一叫未知。 |
| 数据已在本地完成校验与替换 | 数据格式校验通过，已替换当前记录。来源真实性需另行核验。 | 格式校验无法证明数据真实。 |
| 高需求／低已发现供给 | 搜索较多／收录较少 | 散点描述当前数据，避免把搜索次数和有限样本扩大为完整市场判断。 |

主要导航、操作按钮及固定 ARIA 名称保持不变。测试中的搜索空状态文字需同步：还没有这份档案 → 没有找到匹配的档案。参照详情的“查看待确认项”改为“查看未匹配项”，相应内部分页名称从“待确认机制分页”改为“未匹配机制分页”。展示标题另有“记录差异，不等于设计上的有与无”→“先看记录状态，再核对规则差异”、“热度，是线索。”→“先看搜索，再查竞品。”、“把想法变成可验证的问题。”→“这组机制会怎样配合？”。
