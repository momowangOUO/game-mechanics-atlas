# 分类搜索、近期资料与手机阅读

2026-11-02 更新。

## 搜索

分类页与全站搜索共用索引，覆盖维度、分组、原子机制、复合类型和游戏。输入 `RPG`、`auto battler`、`自走棋` 或 `核心交互 跳跃` 可以找到对应资料；名称匹配优先于正文中的提及。复合类型跳转类型详情，游戏跳转案例，机制仍保留原分类路径。

类型目录补充常用别名，游戏目录可用类型名称或 ID 检索。搜索词按空格分别匹配，兼容全角输入和 ID 中的连字符。

## 近期资料

首页与搜索趋势页默认展示截至 2026-11-02 的 Google Trending Now 近七天快照。四个地区分别有 9、6、10、13 个已核对的电子游戏词条，共 38 项记录。地区、走热时间、采集时间、原始档位、来源链接及 SHA-256 随数据保留。

2025 年年度榜单保留为历史资料。近期档位、年度名次、相对指数与实际次数分别建模。类别相对指数的当日请求仍为 HTTP 429，没有用游戏词条生成类别需求或市场机会评分。详见[搜索资料](../real-search-demand.md)。

新增《影之刃零》《魔物猎人旅人》两个 2026 年案例与官方代表图，目录为 82 款游戏、718 条机制记录、156 项来源。旧资料保留原核验日期，不声称全部旧案例都在当天重新研究。[来源与范围记录](../research/2026-game-update.md)

纯赌博、博彩投注和传统棋牌不收录。公开近期快照与来源片段只保留已核对的电子游戏词条，完整官方网页仅在忽略目录中用于核对。[收录范围](../content-scope.md)

## 手机与循环图

- 分类列表、搜索结果、机制目录、游戏目录、类型目录和来源目录可以自然滚动，不要求在手机上逐页翻看。分类逐层导航与研究提示词的分步选择保留。
- 机制说明、边界和游戏实例在手机上完整阅读；实例观察与成立条件放在一起，来源链接保留。
- 三格漫画在手机上纵向连续展示。分类阅读卡增加“看图理解”，目录和游戏机制卡提供带画面预览的同名链接，机制详情页也有直接定位按钮。
- 手机切换分类后回到可见的层级导航，避免点了列表底部后，下一层标题留在屏幕外。
- 循环图保留已有步骤原文。桌面形成顺时针回路，手机竖排并以返回线连接末步与首步；连线按实际卡片尺寸重算。没有整理循环的模式仍显示资料缺口。
