# 本轮验收

资料核对：2026-11-02。最终构建与发布检查跨至 2026-11-03。

## 本地检查

- 类型检查通过；128 项 Vitest 单元测试通过。
- 内容校验通过：513 款游戏、505 款详细案例、8 款参考条目、127 项机制、3572 条机制记录和 1130 项来源。
- 组合校验通过：48 个类型、22 个核心玩法方向、387 个组合已有案例、25 个空缺有检索记录、644 个组合待补查。六个类型未达到十款目标，明确列为资料缺口。
- Agent 数据导出 7 项测试、Windows 路径兼容 24 项测试、静态服务器 2 项测试、搜索资料采集器 3 项测试通过。
- GitHub Pages 子路径生产构建成功，Next.js 生成 789 个静态路由。公开内容目录包含 786 页，其他路由用于站点地图及错误页。
- 静态检查遍历 65,051 处本地链接和资源引用，未发现缺失。新直播索引具有静态 HTML、独立元数据、canonical、Markdown 摘要与结构化资料导出。
- 本地完整执行 131 个浏览器场景，127 项通过，发现四项问题：平板筛选栏溢出、新索引未加入旧 sitemap 断言、新统计字段未加入旧数据断言、分类修正后失效的合作示例。修复并重新构建后，30 项相关回归全部通过；发布流水线再次执行完整测试集。

测试使用 Playwright Chromium，包含 320、390、768 和 1440 像素视口；未声称真机或全浏览器覆盖。

## 实际修复与复核

新增年代测试发现的首次失败来自测试未等待客户端导航完成即返回，已补充 URL 和页面就绪断言。另通过实际截图发现手机游戏目录仍为双列窄卡片，增加卡片宽度回归后确认失败，再接入单列连续样式。网页与研究范围没有为迁就测试改写规则。

768 像素宽度下，筛选项的最小宽度挤压搜索框并超出页面 7 像素。中等屏幕现将搜索放在独立一行，四个筛选项放在下一行；手机保持两列筛选。修后实测页面宽度与文档宽度均为 768 像素。[平板截图](runtime/era-768.png)

分类检查覆盖纯谱面音游与节奏动作的区别、单角色战斗与多单位指挥的区别、原作年份与移植年份、参考条目缺口，以及暂缓候选未进入公开目录。所有审查记录、未确认的资料和数据口径分别保留。
