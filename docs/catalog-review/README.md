## 分类与年代

上一轮的 459 款逐项留下标签审查记录：[原始 82 款](../research/tag-audit-original-2026.json)、[经典 105 款](../research/tag-audit-classics-2026.json)、[手机 105 款](../research/tag-audit-mobile-2026.json)、[现代 167 款](../research/tag-audit-modern-2026.json)。新增作品在各自研究批次中注明类型、核心玩法、范围与来源。

《世界计划》等谱面音游归入节奏游戏，不因操作实时就算动作游戏。《完美音浪》和《节奏地牢》确有直接战斗，因此可以同时具有节奏操作和动作战斗。新增“回合战斗”方向，区分单角色或队伍菜单战斗与多单位战术指挥。移除只因团队战术、物品收集或普通升级而贴上的不当标签；修正《马力欧卡丁车 8》《喷射战士 3》等类型。

原作年代分为 2010 年及以前、2011–2019 年、2020 年及以后，游戏目录与组合查询使用同一判断。以原作首次公开发行年为准，抢先体验和正式发行差异写入范围，移植年份不覆盖原作年份。

## 商业与传播证据

按用户确认的标准，没有公开销量或玩家总数时，可凭明确商业榜单或持续直播表现收录。下载量、评价、观看时长与同时在线人数各自标明口径，不互相换算。

[重点候选审查](../research/admission-review-2026.json)逐项检查 54 个风险候选或反例；其中 32 项保留，22 项暂待更多证据。该文件另有目录身份索引，`index_only` 仅表示建立索引，不表示每款作品都已重新验证商业成绩。暂缓候选的规则资料和来源留在[归档](../research/archive/admission-pending-2026.json)，不等于认定这些游戏玩家少于门槛。六个过度小众的语言解谜候选也留在独立归档，不进入公开案例目录。

[直播与传播案例](https://momowangouo.github.io/game-mechanics-atlas/games/discovery/)保留 Twitch 2026 报告和 Hatchet 2025 报告的观察期与口径，区分全球榜、地区榜、主播个例及 Roblox 平台内作品。未建案例的作品明确标为待补。直播传播只用于发现值得收录的游戏，不加入搜索需求或蓝海评分。

每类十款仍是研究目标。当前 42 个传统类型和全部 22 个核心玩法方向达到目标；自动战斗构筑 8、精确平台跳跃 9、语言解谜 3、战术射击 9、载具竞技 9、社交推理 8，继续补查。387 个组合已有案例，25 个空缺有有限范围检索记录，644 个组合待补查。
