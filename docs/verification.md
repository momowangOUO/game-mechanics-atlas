## 已修复的实际问题

- SVG散点提示由多个子文本改为单字符串，消除服务端与浏览器渲染不一致；回归先失败后通过。
- 安装版Motion的减少动态hook只捕获初值，补充媒体查询实时监听；完整动态中切换系统偏好后回归通过。
- Windows exFAT的普通文件`readlink`返回EISDIR，导致Next文件追踪失败。构建子进程内的局部处理先用lstat确认非符号链接，再规范错误；不修改全局环境、依赖或关闭检查。[上游同类记录](https://github.com/vercel/next.js/discussions/77912)。
- 供给查询补上未观察但已注册的模式，保留未知；缺失主题记录不当成实测零；归因权重变化不伪装为增长。上述领域问题均有先失败后通过的专项回归及独立复核。
- 独立界面审阅发现导入记录随页面导航丢失、快捷搜索焦点不在输入框；增加根级会话数据Provider与搜索弹窗的显式初始焦点。导入→案例→首页→热度、精确JSON导出、错误导入保留、刷新重置，以及Ctrl/Cmd K直接输入均通过专项回归。
- 复核发现混合来源摘要未明确提示合成成分；改为按实际来源集合显示混合与合成声明，覆盖首页、案例和对比页。纯合成、纯外部与混合分支均通过，768／390像素的混合文案布局通过。
- 全分支审阅发现SVG节点原生跳转会重置工作数据，改为保留链接语义的客户端导航；首页与案例SVG的鼠标、键盘、新标签、精确导出及刷新边界均通过生产回归。
- 完整零值数据在共享摘要中曾因相对指数不可算而被当成未采集，改按实际测量状态显示0与0.0%趋势；真正缺失主题继续显示未采集。
- 统计数字的可见span曾被通用说明文字规则缩小，已收窄选择器；实际桌面首页／热度数字为32／30px，手机为26／25px，与其数字容器一致。

部分初次浏览器失败来自测试脚本的文字定位假设及Next流式隐藏片段；最终测试等待真实片段消费完成，再对可操作页面断言，没有为了通过测试删改机制证据或伪造数据。测试终端仍可能显示宿主同时设置NO_COLOR和FORCE_COLOR的Node提示，不影响断言结果。
