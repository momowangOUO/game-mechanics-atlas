# 游戏机制研究站：产品约定

本文件整理用户本次完整需求，供后续制作和验收使用。网站目标是游戏设计研究工具，同时具有可展示的角色、美术与动效完成度。

## 顺序与范围

先环境检查，再真实视觉参考板，再六类高保真预期样张，随后才正式实现网站。最新视觉要求是由用户在参考板中亲自选择接近《凉宫春日》与 Key 社作品的复古画风。未选定之前不继续制作角色和页面。早期“霓虹赛博终端”只是未采用方向。

六类样张：首页桌面、首页手机、机制详情、游戏案例详情、热度分析、混合玩法实验室。每张需有实际文字与完整美术，作为后续网页对照基准。不能把低保真占位图称为完成的样张。

网站本地可运行，最终上传新建 GitHub 私有仓库 `game-mechanics-atlas`。只提交本项目，无自动研究 Agent、定期更新、研究 Actions、抓取平台或复杂后台。

## 页面与行为

- 首页：黑发女仆、定位、搜索、热门机制/类型/组合、机会推荐、案例、图谱、实验室、统计概览。
- 机制：九维浏览、关键词和适用核心玩法筛选；定义、收录/排除边界、反例、误解、价值、风险、适配、难度、案例与搭配。
- 游戏：基本资料、类型、机制实例、范围、循环、资源/成长、创新和借鉴点；机制/循环/关系/热度多视图。
- 图谱：可缩放、拖动、点选、维度过滤、邻接高亮、组合和案例链接。
- 实验室：选择核心交互、附加机制、结构、市场目标；规则分析循环、分工、协同、冲突、风险、Demo验证、案例、调整方向。
- 热度：需求、供给、机会/拥挤指标、趋势、排行、散点图、案例解释、导入入口。示例数据贯穿标明。
- 比较：至少两游戏的机制、结构、资源、构筑与可用热度对比。
- 手机：Tab、底部导航、抽屉、分步选择；不能依赖桌面表格压缩或核心功能超长滚动。

## 数据不变量

固定九维：`interaction`、`rules`、`temporal`、`buildcraft`、`progression`、`economy`、`information`、`participants`、`variability`。每个原子机制有唯一且稳定的主维度。题材、叙事、美术、平台是元数据。类型配方独立记录，不将 Roguelite/RPG/MOBA 等伪装成原子机制。

实例状态：`present`、`absent`、`not_applicable`、`unknown`、`conditional`。未记录和资料不足不能推导为 absent。空维度合法。作用范围支持游戏、模式、系统、章节、角色和版本。不能把有条件规则聚合成无条件存在。

关系独立记录依赖、协同、替代、冲突、资源供给、规则改写和双向反馈，不改变机制分类身份。

实体包含 `Game`、`GameMode`、`Mechanic`、`MechanicInstance`、`CompositeGenre`、`MechanicRelationship`、`HybridRecipe`、`SearchQueryStat`、`TopicHeatProfile`、`Source`。Zod 验证结构和外键；本地可版本控制数据，预留替换接口。

最低内容：18真实游戏、40原子机制、10复合类型、8组合公式、一套搜索种子数据与分析结果。事实、设计分析、推测/未确认分别表达，并提供真实来源。边界包括俄罗斯方块、增量游戏、沙盒、叙事游戏和条件模式。

## 热度原则

需求来自玩家搜索次数/事件，不来自收录游戏数，不把次数当独立人数。供给只代表收录样本中的拥挤度，不能冒充全市场数量。不同样本覆盖和同义词重复会影响结果，页面需可见说明。

按统一时间区间、主题ID与口径汇总搜索，避免将“1000万次某一主题”平均成小类后丢失总量。别名归一后保留来源及分配规则，多主题归因避免重复计入总量。零供给/微小样本需平滑和置信度提示。蓝海/红海公式、参数及示例计算在网站与文档明确公开；得分是研究线索，不是销量预测。

支持本地seed、文件导入与未来日志/API适配，MVP不依赖付费模型、登录或在线Agent。

## 技术与视觉

采用 Next.js / TypeScript、本地数据、Motion、XYFlow、Zod；无需复杂数据库。生产依赖锁定并保留许可证说明。原创黑发女仆独立资产，官方作品仅作视觉参考，不能当成已获商业复用授权。

动效覆盖转场、进场、关系路径、节点高亮、数字、搜索展开、看板娘反应、面板及弹窗。提供 `prefers-reduced-motion`、手机和低性能降级。键盘焦点、关闭弹窗、空状态和无结果反馈必须可用。

## 验收

类型检查、生产构建、数据不变量、需求/供给公式与重复归因边界、实验室规则、路由、搜索/筛选、图谱交互、比较、导入错误、空状态、桌面/手机布局、减弱动态。保存实际截图与测试结果，再提交资源、检查秘密文件与仓库私有状态后推送。
