# Galgame 美术与演出升级

日期：2026-10-31。用户选择「Galgame／旧游戏官网」，并要求按 game-artist 工作流制作。保留原有 Next.js 研究网站，不迁移游戏引擎，不新增研究业务或付费服务。

## 从目标到网站

先制作研究室、欢迎角色与代表性玩法插画，再保存 `design/galgame/` 中六类高保真样张及完成／冲突状态。目标 PNG 与实际运行截图分开。首次目标提交为 `941ece8`，早于本轮 UI 改造。

视觉依据是用户已选的清晰赛璐璐与粗黑线。房间用木色、暮色窗景和暖灯建立纵深；人物、前景、文字与命中区域独立实现。主页采用标题画面、对话框与五个绘制章节入口。机制页用纸张定义区和较大的角色场景；游戏页用主研究纸面与次要线索板；热度页保留真实计算图表，旁边放置纸张观察便签。

正式资源清单见 `assets.json`：50 项，包括41份位图和9枚矢量图标。41份位图中，讲解姿势由原有粗线立绘转换格式，其余40份使用内置 imagegen 分别制作。包括六种角色状态、完整房间与独立桌面前景、五张章节插画、18张玩法示意和10张配方场景。原始 PNG 和修订草稿留在忽略目录；正式 WebP/SVG、提示词、尺寸与哈希随仓库提交。

图像只表达本站美术与玩法概念，不是游戏截图、官方封面、市场证据或模型输出的事实来源。九维图标是独立编写的 SVG。角色不是 Live2D；实际表现方式为姿势切换、二维位移与分层视差。

## 操作与反馈

- 首页点击对话可继续研究建议，角色姿势同步切换，搜索草稿保留。
- 实验室添加／移除机制时，机制卡和连线反馈对应真实选择；关系中的冲突或替代可标明具体机制对。
- 分析立即提交不可变结果快照，随后播放短盖章与角色演出。完成只表示整理好规则分析，不代表设计或商业成功。
- 连续操作可取消旧演出；修改机制后显示上次结果与更新入口，不把旧结果冒充当前结果。
- 动效开启时使用分层视差、章节方向转场、卡片反馈、结果展开和角色反应。系统减少动态优先，关闭循环／大位移；文字和操作不等待动画。

## 手机与可达性

首页采用独立标题画面与六个章节／对比入口，不把桌面长首页压缩后堆叠。实验室按核心、配料、目标、结果推进；紧凑视口进一步拆核心选项、当前机制、报告概况与研究内容，长报告按语义分页。未知、条件存在、来源边界与完整内容均保留。

本轮无整页滚动约束的重点是手机首页与实验室的当前操作屏；研究网站的桌面档案仍使用正常浏览器纵向阅读，原有其他研究页面保留其检索、页签、详情与阅读方式。没有将其冒称为全站所有视图都单屏。桌面模拟手机尺寸不等于真机验收。
