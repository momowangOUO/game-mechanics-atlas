## 评审依据与范围

已实际打开 `design/galgame/targets/` 的全部 9 张目标原图，包含首页桌面/手机、游戏详情、机制详情、热度观察，以及实验室初始/完成/冲突/手机状态。依据为房间与桌面空间、粗线赛璐璐成年女仆形象、绘制插画、纸张与深色研究框、角色与结果的状态关系；没有用评分代替逐项判断。

本轮使用 Edge 无头浏览器运行当前开发服务，通过 Playwright 实际操作并保存原始截图。桌面检查采用 1440×1000 或 1440×1050；首页和实验室还检查 390×844、320×844，问题复现与修复检查采用 320×640。实际打开了报告引用的截图。评审未修改生产代码，仅保存捕获脚本、截图和本报告。

## 其他已执行检查

- 首页桌面保留研究室景深、原创 RIN、动态文字、搜索与对话框。390×844、320×844 的角色、搜索、对话和章节入口均可见，页面宽高与视口一致。
- 实验室默认组合分析后出现完成角色与印章，结果标题获得焦点。修改核心后保留上次结果并显示过期提示，重复分析使用最新核心。
- 实时推进与轮流行动同时存在时，实际显示冲突角色、印章和标记卡对。配方本身的待验证张力也能驱动提醒状态；它来自现有规则数据。
- 开启完整动效时，`revealing` 阶段结果页签已能操作；演出期间切到“风险与 Demo”，演出结束后仍保持所选页签。没有观察到阻塞操作的虚假进度。
- 系统减弱动态效果时，页面为 `data-effects=reduced`。主动阻断房间、角色和前景图后出现 3 个替代显示，390×844 布局保持完整，搜索仍能打开。
- 实验室 390×844 与 320×844 的初始、结果视图不产生整页滚动；手机概况页显示角色与结果状态。320×640 的过期风险页另经 I4 复核。
